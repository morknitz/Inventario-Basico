# INVENTARIO BÁSICO EN PYTHON

Sistema de gestión de inventario básico pensado para la terminal, desarrollado como parte de mi aprendizaje académico.

 ## --Descripción 

inventario_basico es un programa sencillo en Python que permite administrar un listado de productos a través de un menú interactivo. Todo el código está estructurado en funciones organizadas.

 ## --Funcionalidades:

➕ Agregar productos: Permite registrar nuevos elementos en el inventario.

📋 Mostrar productos: Despliega la lista general de todos los productos registrados.

🔍 Buscar producto: Permite consultar la información de un producto específico.

✏️ Modificar producto: Actualiza los datos de un producto existente.

❌ Eliminar producto: Remueve un producto del inventario.

🚪 Salir: Cierra el programa de manera segura.



## 💻 ¿Cómo ejecutar este proyecto?

1. Asegúrate de tener Python 3 instalado en tu equipo.

2. Clona este repositorio o descarga el archivo .py:

    git clone https://github.com/morknitz/inventario_basico.git

3. Navega hasta la carpeta del proyecto y ejecuta el archivo desde tu consola:

    python inventario_basico.py
